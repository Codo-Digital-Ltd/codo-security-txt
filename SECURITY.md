# Security policy

## Reporting a vulnerability

Please email **security@cododigital.co.uk** with the details and steps to reproduce. Do not open a public issue for a vulnerability.

We aim to acknowledge a report within 3 working days and to tell you what we plan to do within 10.

## Supported versions

Only the latest release on WordPress.org receives security fixes.

## Scope

This plugin only publishes a text file and has an admin settings screen. Reports about the settings screen (capability and nonce checks, input validation, output escaping) and about how the file is served are in scope.
